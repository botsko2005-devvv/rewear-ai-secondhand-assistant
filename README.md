# ReWear AI

Мобільний AI-помічник продавця секонд-хенду (OLX, eBay, Grailed).

## Ідея
Користувач вводить короткий опис вживаної речі. Застосунок надсилає його на
backend, де AI визначає категорію, оцінює стан, пропонує діапазон ціни в
гривнях та генерує заголовок і опис оголошення. Результати зберігаються в
локальній історії на пристрої.

## Галузь
Торгівля (онлайн-торгівля вживаними речами).

## Технології (попередньо)
- Android: Kotlin, Jetpack Compose, Retrofit, Room
- Backend: Python, FastAPI, Pydantic
- AI: зовнішній LLM API + Mock-провайдер для тестів

## Функціональні вимоги
1. Введення опису речі та вибір стану
2. Валідація введення
3. Запит на backend через HTTP API
4. AI: категорія, ціна, заголовок, опис
5. Стани UI: початковий, завантаження, успіх, помилка, повтор
6. Копіювання тексту оголошення
7. Локальна історія результатів
8. Ендпоінт /health і конфігурація через environment variables

## Статус
Лабораторна робота №1: налаштування середовища та концепція.

Дисципліна: Програмування мобільних додатків.
