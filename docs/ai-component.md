# AI-компонент системи

## Функція AI у сценарії
AI-компонент (`backend/ai_provider.py`) виконує три задачі обробки тексту:
1. **Класифікація товару** за ключовими словами опису в одну з 6 категорій одягу, взуття чи аксесуарів.
2. **Оцінка цінового діапазону** (`price_min` – `price_max` у гривнях) з урахуванням базової вартості категорії та коефіцієнта стану (`condition`).
3. **Генерація структурованого заголовка й тексту оголошення**, готового для копіювання на OLX, eBay або Grailed.

## Поточна реалізація (`MockProvider`)
У MVP використовується детермінований правиловий провайдер `MockProvider`, який працює локально без зовнішніх API-ключів:

- **Категорії та базові ціни:**
    - *Куртки та верхній одяг* (`куртк`, `пуховик`, `вітровк`, `пальто`) — `800 грн`
    - *Взуття* (`кросівк`, `черевик`, `туфл`, `кеди`, `чобот`) — `700 грн`
    - *Джинси та штани* (`джинс`, `штани`, `брюки`) — `500 грн`
    - *Сукні та спідниці* (`сукн`, `плаття`, `спідниц`) — `450 грн`
    - *Аксесуари* (`сумк`, `рюкзак`, `ремінь`, `шапк`, `шарф`, `годинник`) — `350 грн`
    - *Футболки та светри* (`футболк`, `светр`, `худі`, `кофт`, `толстовк`) — `300 грн`
- **Коефіцієнти стану (`CONDITION_FACTOR`):** `new = 1.0`, `excellent = 0.8`, `good = 0.6`, `fair = 0.4`.
- **Розрахунок ціни:** `price_min = round(price * 0.85, -1)`, `price_max = round(price * 1.15, -1)`.
- **Оцінка впевненості (`confidence`):**
    - `0.9` — категорію визначено, довжина опису > 30 символів;
    - `0.7` — категорію визначено, короткий опис (≤ 30 символів);
    - `0.3` — категорію не розпізнано (оскільки `0.3 < CONFIDENCE_THRESHOLD=0.5`, сервер повертає `status: "low_confidence"`).

## Захист, тестові тригери та розвиток
- Перед викликом AI сервер відсіює заборонені слова (`BANNED_WORDS` у `backend/main.py`, HTTP `422`).
- Для тестування відмовостійкості закладено тригери: `__ai_error__` (`AIError` → HTTP `502`), `__timeout__` (`TimeoutError` → HTTP `504`) та `__bad_json__` у `main.py`.
- На наступних етапах планується виділення абстрактного інтерфейсу `AiProvider` із можливістю підключення зовнішнього LLM API через змінні середовища у `.env`.
