# Контракт REST API

Базова адреса (локально): `http://127.0.0.1:8000`  
Інтерактивна документація: `/docs` (Swagger UI).

## 1. Перевірка доступності сервісу
- **Метод і шлях:** `GET /health`
- **Відповідь `200 OK`:**
```json
{
  "status": "ok"
}
```

## 2. Генерація оголошення
- **Метод і шлях:** `POST /api/v1/listing`
- **Заголовок:** `Content-Type: application/json`

### Вхідні дані (`ListingRequest`)
Ручний вибір категорії у запиті відсутній — категорію визначає AI-компонент на backend.

| Поле | Тип | Обов'язкове | Правила валідації |
|---|---|---|---|
| `description` | `string` | Так | 1–500 символів після обрізання пробілів (`strip()`), не може бути порожнім |
| `condition` | `enum` | Так | Одне зі значень: `"new"`, `"excellent"`, `"good"`, `"fair"` |
| `size` | `string \| null` | Ні | Рядок до 10 символів або `null` |
| `platform` | `enum` | Ні | Одне зі значень: `"OLX"`, `"eBay"`, `"Grailed"` (за замовчуванням `"OLX"`) |

### Приклад коректного запиту
```json
{
  "description": "Куртка Zara, розмір M, носив один сезон, дрібна потертість на рукаві",
  "condition": "good",
  "size": "M"
}
```

### Успішна відповідь (`200 OK`, `status: "ok"`)
```json
{
  "status": "ok",
  "category": "Куртки та верхній одяг",
  "condition": "good",
  "price_min": 410,
  "price_max": 550,
  "currency": "UAH",
  "title": "Куртка Zara, розмір M",
  "description": "Куртка Zara, розмір M, носив один сезон, дрібна потертість на рукаві. Стан: добрий. Категорія: Куртки та верхній одяг. Орієнтовна ціна: 410–550 грн.",
  "hint": null,
  "confidence": 0.9
}
```

### Відповідь при низькій впевненості (`200 OK`, `status: "low_confidence"`)
```json
{
  "status": "low_confidence",
  "category": null,
  "condition": "good",
  "price_min": null,
  "price_max": null,
  "currency": "UAH",
  "title": null,
  "description": null,
  "hint": "Не вдалося визначити річ. Уточніть опис: вкажіть тип речі, бренд і стан.",
  "confidence": 0.3
}
```

## 3. Формат помилок (`ErrorResponse`)
Усі помилки повертаються у єдиному JSON-форматі без внутрішнього `stack trace`:
```json
{
  "error": "код_помилки",
  "message": "Зрозуміле повідомлення українською мовою"
}
```

| HTTP-код | Код (`error`) | Коли виникає |
|---|---|---|
| `422` | `validation_error` | Порожній опис, довжина > 500 символів або некоректний `condition` |
| `422` | `forbidden_item` | В описі знайдено заборонені товари (`BANNED_WORDS`) |
| `502` | `ai_error` | Помилка виконання AI-компонента |
| `504` | `ai_timeout` | Перевищено час очікування відповіді від AI-компонента |
