# Відомі обмеження поточної версії

1. **Rule-based AI замість реального LLM:** `MockProvider` працює за фіксованим словником коренів українських слів. Якщо ввести лише назву бренду без типу речі або англійською мовою, система може повернути `low_confidence`.
2. **Правиловий характер словників брендів і дефектів (ЛР6):** класифікація сегмента бренду (`brand_tier`) та облік дефектів спираються на фіксовані словники та ключові слова. Бренди або специфічні пошкодження, не внесені до словників, визначаються за замовчуванням або ігноруються.
3. **Евристичний характер `confidence` та підказок (ЛР6):** оцінка впевненості та генерація швидких підказок (`suggestions`) базуються на евристичних правилах довжини тексту й наявності ключових слів, а не на глибокому семантичному аналізі моделі LLM.
4. **Відсутність аналізу зображень:** опис і ціна формуються виключно за текстовим введенням без обробки фотографій речі.
5. **Відсутність акаунтів і прямої публікації:** застосунок готує текст для копіювання в буфер обміну, без інтеграції з API OLX, eBay чи Grailed.
6. **Лише локальне розгортання:** backend працює локально (`127.0.0.1:8000` через `adb reverse`) без хмарного хостингу та HTTPS.
7. **Відсутність офлайн-черги та хмарної синхронізації:** локальна історія зберігається лише на пристрої у Room Database і не синхронізується з хмарою.
