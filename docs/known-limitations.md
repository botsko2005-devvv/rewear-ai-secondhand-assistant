# Відомі обмеження поточної версії

1. **Rule-based AI замість реального LLM:** `MockProvider` працює за фіксованим словником коренів українських слів. Якщо ввести лише назву бренду без типу речі (наприклад, *«худі»* не вказано, написано лише *«Stone Island M»*) або англійською мовою, система поверне `low_confidence`.
2. **Оцінка ціни без урахування бренду та матеріалу:** базова ціна визначається лише за категорією та коефіцієнтом стану (`condition`), тому преміальні та бюджетні речі однієї категорії отримують однаковий діапазон.
3. **Відсутність локальної історії та екрана деталей:** згенеровані оголошення не зберігаються після закриття застосунку (реалізація Room Database запланована на ЛР4).
4. **Відсутність аналізу зображень:** опис і ціна формуються виключно за текстовим введенням без обробки фотографій речі.
5. **Відсутність акаунтів і прямої публікації:** застосунок готує текст для копіювання в буфер обміну, без інтеграції з API OLX, eBay чи Grailed.
6. **Лише локальне розгортання:** backend працює локально (`127.0.0.1:8000` через `adb reverse`) без хмарного хостингу та HTTPS.
